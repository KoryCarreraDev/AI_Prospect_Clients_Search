# Empresa Ejemplo (ficticia)

Configuración y datos completamente inventados para probar la herramienta de punta a punta. Nada de esto es real: la empresa, la marca, los productos, el certificado y los prospectos son ficticios, y los correos y teléfonos usan dominios y números reservados de ejemplo.

Para probarla en una copia de la carpeta (sin tocar tus datos):

1. Copia `config/` a la carpeta `config/` del proyecto y `datos_usuario/` a `datos_usuario/` (ambas están en `.gitignore`).
2. Ejecuta `/estado`, `/borrador Librería Ejemplo Uno`, `/exitoso`, `/venta` y `/baja`.

`/empezar` también ofrece cargar este ejemplo si `config/` y `datos_usuario/` están vacías.
