# Mensajes que funcionaron

El agente toma de ellos la estructura y el tono, no el texto. Un mensaje entra aquí solo cuando el usuario lo confirma, después de una respuesta real. Sin datos de contacto del prospecto.

**Niveles:** 1 = respondió · 2 = respondió con interés o preguntas · 3 = pidió muestra, cotización o reunión.

Máximo unos 8 por segmento; se quita el de menor nivel. Se agregan con `/exitoso`.
