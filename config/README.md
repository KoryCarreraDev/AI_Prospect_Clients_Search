# config/

Aquí vive la configuración de quien usa la herramienta: empresa, marcas, productos, asesores, voz, certificados, claims, historias de éxito, región, ley, fuentes y políticas.

Esta carpeta está en `.gitignore`: nada de lo que escribas aquí se sube al repositorio. Se llena con `/empezar` a partir de las plantillas de `plantillas/config/`.
